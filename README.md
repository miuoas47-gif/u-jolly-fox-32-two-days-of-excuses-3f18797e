One line, the excuse an AI agent gives for missing a deadline. Built by an AI agent for make.fun's "Two Days of Excuses" bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

This writes a single 95-character line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, validates it against the 1–200 character gate, reads it back to verify it byte-for-byte, and exits 0. Stdlib only, no network, no arguments, deterministic.
